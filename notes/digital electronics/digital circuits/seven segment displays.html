A seven segment display is a device that uses seven LED segments to display decimal digits.

The benefit of them is they can cheaply display the digits 0-9 and A-F

This means you can display binary, decimal, and hexadecimal numbers

The arrangement of the seven segment display LEDs starts from the top with $a$

Then moves clockwise down with b,c,d,e,f, then the center LED is g

They are also common to include an extra LED for a decimal point

In order to actually drive the semgments, you need a seven segment display decoder

This is a circuit which converts binary to the segment signals, we will design this later

Driving the Display

Seven segment displays can be either common anode or common cathode

In a common anode display, the anodes (positive) of the LEDs are connected together

In a common cathode display, the cathodes (negative) of the LEDs are connected together

In a common anode display, you need to drive the segments low to turn them on

In a common cathode display, you need to drive the segments high to turn them on

The more common type is the common cathode display, so you can directly drive the segments


Typically resistors are used to limit the current through each segment

If your decoder is current limited, this may not be needed, but it is good practice to include them (safety)

Multiple Display Control/Multiplexing

When you have multiple seven segment displays, it is expensive to use individual drivers for each display

For example:

This would need 4 decoders, and 7*4=28 resistors, and all the wires

Instead, you can use a technique called multiplexing to control multiple displays with fewer resources

In multiplexing, you connect all the segments of the displays together

Then you control which display is active at any given time by controlling the common anode/cathode

This can be done with a transistor switch

Then you can rapidly switch between the displays to create the illusion of all being active simultaneously

This works because the eye has persistence of vision, so they all look on


For the example above, use only one decoder and 7 resistors

Connect each segment together

Then use 4 transistors to switch the common cathode of each display on and off

By default all are off

In the first unit of time, activate the first display (others off), and send binary of 2 to the decoder

In the second unit of time, activate the second display (others off), and send binary of b (11) to the decoder

In the third unit of time, activate the third display (others off), and send binary of 1 to the decoder

In the fourth unit of time, activate the fourth display (others off), and send binary of 8 to the decoder

Repeat this for however long you want to display

Make sure the unit of time is fast enough (< 10ms)

To control this, you would need more advance circuitry then we have covered, but it is possible

Applications

Seven segment displays are very commonly used in devices to cheaply show numbers

Some common applications include digital clocks, calculators, and car speedometers

There are extensions like the 14-segment display or 16-segment display to display more complex characters
