So far, we have made and designed some digital circuits

But the issue is it's difficult to test them before building them

To solve this problem, we can use a software called Logisim Evolution

Download (Requires Java) (If on windows, select .msi file)

Building Circuits

Opening Logisim, we can start building our digital circuits.

All of the digital circuit we learn about later can be either found or implemented in Logisim.

Right now we will just focus on using the gates, on the side panel open the folder that says gates

To place a gate, select the gate from the folder and hover onto the canvas. left click to place it.

You can also use the toolbar at the top to quickly choose a gate

The circuit we will simulate for this example will be $y = ab + bc + b'c$

This will require three AND gates, a NOT gate, and a three input OR gate

To make the OR gate 3 input, select it and under properties, change the number of inputs to 3

To select an object, first select the pointer icon at the top bar and select the component

Now we need to add inputs and outputs, we do this using pins

You can find pins at the top bar, they look like the squares with the triangles at the end

The one with a line pointing right is input and the one with a line pointing left is output

To use the pins, we need to rename them, this can be done by either double-clicking on and setting the name

Or selecting the pin and changing the name under properties

For this example we need three input pins $a,b,c$ and one output pin $y$

After we have all our components placed, we can connect them with wires

To connect them, drag from the green circle the draw wires between

A solid green dot on a wire indicates a split or junction

Testing Circuits

To test the circuit, we can click on the input pins to change their value

We first need to switch to simulation mode by selecting the hand icon next to the pointer icon

After that we can click on the input pins and see the wires light up if it's a 1

We can also click the wires to see the values

Making Truth Tables and SOP

Logisim also has a built in feature to make truth tables and SOP forms

It utilizes the pin names, which is why we need to name our pins appropriately

This can be done under Project > Analyze Circuit and selecting either expression or table

Exporting Circuit Images

To export the circuit as an image, go to File > Export Image

You can choose the format (PNG, SVG, etc.)

Subcircuits

Sometimes you need to repeat circuits, and this can be done by copy and pasting

But that will lead to a cluttered design and make it harder to maintain

We can create subcircuits to encapsulate and reuse components in a nicer package

This can be done by selecting the green plus icon under design

After that, you can give the subcircuit a name and start designing it

For example I will make a subcircuit for a full adder

Conclusion

Logisim is a powerful tool for simulating digital circuits and can help you design and test your circuits efficiently.
