A first-order linear differential equation is an equation of the form:

$$\frac{dy}{dx} + P(x)y = Q(x)$$

Where $P(x)$ and $Q(x)$ are functions of $x$.

To solve this type of equation, we can use an integrating factor, which is given by:

$$\mu(x) = e^{\int P(x) dx}$$

Multiplying both sides of the original equation by the integrating factor, we get:

$$\mu(x)\frac{dy}{dx} + \mu(x)P(x)y = \mu(x)Q(x)$$

The left side of this equation is the derivative of $\mu(x)y$ with respect to $x$:

$$\frac{d}{dx}[\mu(x)y] = \mu(x)Q(x)$$

Integrating both sides with respect to $x$:

$$\mu(x)y = \int \mu(x)Q(x) dx + C$$

Finally, solving for $y$:

$$y = \frac{1}{\mu(x)}\left(\int \mu(x)Q(x) dx + C\right)$$

Derivation

Our original function is in the form of

$$\frac{dy}{dx} + P(x)y = Q(x)$$

This almost looks like the derivative of a product (product rule):

$$\frac{d}{dx}[f(x)g(x)] = f'(x)g(x) + f(x)g'(x)$$

If we have an integrating factor $\mu(x)$, we can multiply the entire equation by it:

$$\mu(x)\frac{dy}{dx} + \mu(x)P(x)y = \mu(x)Q(x)$$

The left side of this equation is the derivative of $\mu(x)y$ with respect to $x$:

$$\frac{d}{dx}[\mu(x)y] = \mu(x)Q(x)$$

This would mean

$$\frac{d}{dx}[\mu(x)y] = \mu(x)\frac{dy}{dx} + \mu'(x)y = \mu(x)\frac{dy}{dx} + \mu(x)P(x)y$$

So $$\mu'(x) = \mu(x)P(x)$$

This becomes a separable differential equation

$$\frac{d\mu}{dx} = P(x)\mu$$

$$\frac{1}{\mu}d\mu = P(x)dx$$

$$\int \frac{1}{\mu}d\mu = \int P(x)dx$$

$$\ln|\mu| = \int P(x)dx + C$$

$$\mu = e^{\int P(x)dx + C_0} = e^{C_0}e^{\int P(x)dx} = C e^{\int P(x)dx}$$

This $C$ term is just a constant of integration, which is going to be considered at the end

We can ignore the C term by setting $C_0 = 0$/$C=1$:

$$\mu = e^{\int P(x)dx}$$


If we go back to our original equation:

$$\frac{d}{dx}[\mu(x)y] = \mu(x)Q(x)$$

Integrating both sides with respect to $x$:

$$\mu(x)y = \int \mu(x)Q(x) dx + C$$

Finally, solving for $y$:

$$y = \frac{1}{\mu(x)}\left(\int \mu(x)Q(x) dx + C\right)$$

Examples

$$\begin{align} \frac{dy}{dt} + \frac{4}{t}y = t^4 \end{align}$$

$$\begin{align} \mu(t) = e^{\int \frac{4}{t} dt} = e^{4\ln|t|} = t^4 \end{align}$$

$$\begin{align} \frac{d}{dt}[t^4y] &= t^4\cdot t^4 = t^8 \\ t^4y &= \int t^8 dt + C = \frac{t^9}{9} + C \\ y &= \frac{t^5}{9} + \frac{C}{t^4} \end{align}$$


$$\begin{align} x\frac{dy}{dx} - 2x^2y = 6x^2 \end{align}$$

This is not in the standard form, so we need to divide by $x$:

$$\begin{align} \frac{dy}{dx} - 2xy = 6x \end{align}$$

$$\begin{align} \mu(x) = e^{\int -2x dx} = e^{-x^2} \end{align}$$

$$\begin{align} \frac{d}{dx}[e^{-x^2}y] &= e^{-x^2}\cdot 6x \\ e^{-x^2}y &= \int 6xe^{-x^2} dx + C = -3e^{-x^2} + C \\ y &= -3 + Ce^{x^2} \end{align}$$

Practice Problems
  • $\cos(x)\frac{dy}{dx} + \sin(x)y = x\cos^2(x)$

    $$\begin{align} \cos(x)\frac{dy}{dx} + \sin(x)y &= x\cos^2(x) \\ \frac{dy}{dx} + \tan(x)y &= x\cos(x) \\ \mu(x) = e^{\int \tan(x) dx} &= e^{-\ln|\cos(x)|} = \sec(x) \\ \frac{d}{dx}[\sec(x)y] &= x\cos(x)\sec(x) = x\\ \sec(x)y &= \int x \ dx + C = \frac{x^2}{2} + C \\ y &= \frac{x^2}{2}\cos(x) + C\cos(x) \end{align}$$

  • $t^2\frac{dy}{dt} + \frac{dy}{dt} + 4ty = \frac{t}{(t^2+1)^2}$

    $$\begin{align} t^2\frac{dy}{dt} + \frac{dy}{dt} + 4ty &= \frac{t}{(t^2+1)^2} \\ (t^2+1)\frac{dy}{dt} + 4ty &= \frac{t}{(t^2+1)^2} \\ \frac{dy}{dt} + \frac{4t}{t^2+1}y &= \frac{t}{(t^2+1)^3} \\ \mu(t) = e^{\int \frac{4t}{t^2+1} dt} &= e^{2\ln|t^2+1|} = (t^2+1)^2 &&\text{$u = t^2 + 1, du = 2t \, dt$}\\ \frac{d}{dt}[(t^2+1)^2y] &= \frac{t}{(t^2+1)^3}(t^2+1)^2 = \frac{t}{t^2+1} \\ (t^2+1)^2y = \int \frac{t}{t^2+1} dt + C &= \frac{1}{2}\ln|t^2+1| + C \\ y = \frac{\ln|t^2+1|}{2(t^2+1)^2} + \frac{C}{(t^2+1)^2} &= \frac{\ln(t^2+1) + 2C}{2(t^2+1)^2} \end{align}$$
